# Quick Run

One-tap save & run in AcodeX terminal.

## Usage

Tap the floating button to save and run the current file in AcodeX terminal.

## Settings

- **Run command** — command to execute (default: `python '{file}'`)
- **Button size** — size in px (default: 60)
- **Button bottom** — distance from bottom in px (default: 230)
- **Button right** — distance from right in px (default: 14)
- **Button color** — CSS color (default: #2196F3)
- **Save before run** — save file before running (default: true)
